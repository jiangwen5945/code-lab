# code-lab

姜文的前端代码实验室 & 个人作品集。

## 项目简介

基于 Vue 3 + Vite 构建的多入口项目，目前包含两大部分：

- **个人作品集**（`index.html`）— 展示页，包含个人简介、服务范围、项目作品、联系方式
- **代码实验室**（`zendo.html`）— 前端技术演示合集，涵盖 CSS 特效、ECharts 图表、自定义指令、Element Plus 组件封装、WangEditor 富文本编辑器等，支持嵌入外链页面

## 技术栈

- Vue 3 + Vue Router + Pinia
- Vite 5
- Element Plus
- ECharts 5
- GSAP 动画
- WangEditor
- Axios
- Sass
- ESLint + Prettier

## 快速开始

```sh
npm install
npm run dev
```

### 构建

```sh
npm run build
```

### 代码检查

```sh
npm run lint
```
